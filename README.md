**Project Title :💰 Compensation & Rewards Analytics Dashboard | Power BI**

**Description**
An interactive Power BI dashboard designed to analyze employee compensation data, providing insights into payroll costs, salary distribution, bonuses, increments, and department-wise compensation. The dashboard enables HR and business leaders to make data-driven compensation and workforce planning decisions.

**Tech Stack**
Power BI Desktop
Power Query (Data Cleaning & Transformation)
DAX (Measures & Calculated Columns)
Microsoft Excel (Data Source)
Data Modeling
Interactive Slicers & Filters
KPI Cards
Data Visualization

**Data Source**
Type: Simulated HR Compensation Dataset
Format: Microsoft Excel (.xlsx)
Records: Employee compensation and workforce data including salary, bonus, grade, department, location, and performance.

*Note: This project uses fictional data created for learning and portfolio purposes.*

**Dashboard Highlights**
Executive KPI Cards (Employees, Total CTC, Average CTC, Bonus & Increment)
Compensation Breakdown (Base Salary, Bonus & Variable Pay)
Salary Band Distribution
Department-wise Compensation Analysis
Grade-wise Compensation Analysis
Interactive Filters (Department, Location, Gender, Grade, Status & Rating)

**Business Value**
This dashboard helps HR and Compensation teams:
Monitor payroll costs
Analyze salary distribution
Compare departmental compensation
Support compensation planning
Identify workforce compensation trends
